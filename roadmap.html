Final Project — EngineX

High-Performance In-Memory Distributed Key-Value Store

Build a distributed, thread-safe, low-latency database engine from scratch in C++20 that:

  • implements zero system calls on the hot path (io_uring or a custom epoll-based event loop)
  • uses lock-free concurrent memory structures for its core indexes (Track 6's skip list, Track 5/6's queues)
  • persists via a crash-consistent, log-structured write path (Track 6)
  • replicates state across nodes using a custom network protocol, authenticated with your own RSA implementation (Track 7)
  • is driven, under the hood, by the allocator you wrote in Track 3
  • is load-tested and capacity-planned using the Poisson/Markov-chain modeling from Track 6
