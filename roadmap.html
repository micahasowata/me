0. Starting Point

  • Baseline: sophomore CS, zero depth in algorithms, discrete math, systems. GitHub empty.
  • "Starting from zero" — no assumed mastery. Every concept built explicitly.
  • Success after one year: fluent C++, CLRS through graphs, math maturity, Rust, OCaml exposure, 4+ production-quality repos.

✨ Philosophy

Subtract and push. No new books, languages, side-projects. Execution, not curation.

Outwork everyone by being bored. Competence is built in the boring middle.

Depth beats breadth. Compilers, databases, low-latency — all depth disciplines.

⛔ The Rules

  • No textbook substitutions.
  • No new languages beyond C++, Rust, OCaml.
  • No projects outside the ladder.
  • No phase transitions without exit criteria.
  • No reading without implementing.
  • No GitHub activity for its own sake.
  • No roadmap redesign mid-phase.
